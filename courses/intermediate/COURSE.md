# Intermediate Course — DevOps Engineering

## Entry profile

Engineer who can work with development tools and basic command-line workflows but needs systematic production engineering depth.

## Major projects

I1 — Production Kubernetes platform:
deployment, networking, configuration, storage, health, scaling and failure recovery.

I2 — Infrastructure + observability:
Terraform, CI/CD, logging, metrics, traces, alerting, SLOs and controlled changes.

I3 — Integrated production platform:
application, Kubernetes, infrastructure, observability, database, recovery and incident response as one operating system.

## Teaching model

Theory is deep but distributed through:
- visualized React stories
- project work
- failure labs
- diagnostic scenarios
- production design exercises

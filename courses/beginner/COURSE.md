# Beginner Course — DevOps Through Problems

## Entry profile

Strong software/application engineer with limited operational experience.

## Teaching sequence

Start with a concrete distributed application problem, then introduce:
Linux -> networking -> protocols -> containers -> orchestration -> CI/CD -> infrastructure -> reliability.

Tool introduction always answers a real operational problem.

## Major projects

B1 — Containerized application:
frontend + API + database, operated locally.

B2 — Productionized service:
CI/CD, health checks, logs, monitoring, backup and controlled failure.

B3 — Distributed service:
asynchronous work, queueing, retries, idempotency and failure recovery.

## Assessment

Every section uses:
- Conceptual form
- Diagnostic form
- Hands-on form

Every form uses multiple difficulty bands.

## Completion status

The authored Beginner core is complete: all seven sections have lesson coverage, prerequisite diagnostics, pilot assessment banks, hands-on task contracts, project links and spoken scripts. The runtime machine-verification layer is intentionally still separate and is not claimed as complete.

## Prerequisite diagnostics

The current adaptive pilot includes B-F1, B-F2, B-A1, B-A2 and B-A3. A diagnostic recommendation may compress introductory theory, but the associated exercise remains mandatory.

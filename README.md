# DevOps Programme

A multi-course, multi-modal DevOps learning system for a strong software engineer.

## Programme

- `courses/beginner/`: DevOps through concrete problems
- `courses/intermediate/`: deep production DevOps engineering
- `courses/advanced/`: large-scale distributed systems and operations
- `foundations/`: reusable Linux, OS, networking, protocols, database, distributed-systems and reliability competencies
- `projects/`: continuous project instances, including external learner projects
- `exams/`: standardized assessment architecture
- `platforms/`: macOS, Linux and Windows environment profiles
- `app/`: adaptive learning/co-teacher application
- `podcasts/`: spoken learning scripts
- `book/`: long-form curriculum

## Learning loop

Understand -> Predict -> Operate -> Break -> Diagnose -> Repair -> Recall -> Design

Theory can be skipped when demonstrated knowledge is sufficient. Required exercises cannot be skipped.

## Assessment

Every section has three assessment families:

1. Conceptual — mechanism and prediction.
2. Diagnostic — evidence-based troubleshooting.
3. Hands-on — demonstrated operation and recovery.

Every exam form contains controlled difficulty variation. Forms are generated from an assessment blueprint rather than from ad-hoc randomization.

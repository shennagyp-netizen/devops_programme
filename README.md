# DevOps Programme

Five-day intensive DevOps learning system for a strong software engineer.

Surfaces:
- book/curriculum.tex: multi-level enumerated curriculum
- podcasts/: normal-text scripts for Google AI Studio / Gemini TTS
- app/: React interactive learning environment
- prompts/: generation prompts
- PLAN.md: milestones and acceptance criteria

Mastery loop:
Understand -> Predict -> Operate -> Break -> Diagnose -> Repair -> Recall -> Design

The programme deliberately rebuilds networking from first principles and reviews Linux/terminal operationally.

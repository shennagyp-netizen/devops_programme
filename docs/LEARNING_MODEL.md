# Learning Model

Each concept is represented as textbook + podcast + co-teacher + motion + Mac lab + retrieval + deliberate failure + production design.

The podcast is intentionally exercise-driven. The learner is not a passive listener:
1. Predict before the explanation.
2. Listen for the causal mechanism.
3. Pause and explain the mechanism in their own words.
4. Operate the system on the Mac.
5. Break one variable deliberately.
6. Diagnose from evidence.
7. Retrieve without notes.
8. Transfer the mechanism to production scale.

The React app is the co-teacher layer. It does not replace the spoken lesson. It controls the exercise loop around the audio, exposes the transcript only when needed, records predictions and retrieval answers locally, and makes the learner prove understanding before moving on.

Mastery:
1. Recognition
2. Explanation
3. Prediction
4. Operation
5. Failure engineering
6. Diagnosis and repair
7. Design

Core loop:
Understand -> Predict -> Operate -> Break -> Diagnose -> Repair -> Recall -> Design

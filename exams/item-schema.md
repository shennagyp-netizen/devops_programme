# Assessment Item Schema

Minimum item metadata:

```
id
course_id
section_id
competency_id
objective_id
assessment_family
item_type
difficulty_target
cognitive_level
expected_time
prerequisites
prompt_or_scenario
answer_or_evidence_spec
scoring_rubric
accessibility_profile
security_class
version
status
```

Hands-on items additionally define:

```
environment_profile
initial_state
allowed_operations
success_observations
failure_conditions
recovery_requirements
evidence_requirements
reset_strategy
```

Author difficulty is provisional. Observed performance is recorded separately.

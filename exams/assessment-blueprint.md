# Section Assessment Blueprint

A section assessment blueprint must specify:

| Dimension | Requirement |
|---|---|
| Assessment family | conceptual / diagnostic / hands-on |
| Competency coverage | explicit competency IDs |
| Difficulty | controlled distribution across forms |
| Cognitive level | mechanism / application / diagnosis / design as appropriate |
| Item type | selected response / constructed response / scenario / hands-on |
| Time | target and acceptable range |
| Scoring | criterion and/or blueprint weights |
| Form equivalence | comparable coverage and difficulty |
| Accessibility | declared accommodations |
| Security | operational item-pool status |

The generator must reject a form that does not satisfy its blueprint.

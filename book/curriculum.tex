\chapter*{Mission}
This programme consolidates strong software knowledge into operational DevOps competence. Networking is rebuilt from first principles. Linux and terminal usage are reviewed. All later tools are connected to the same systems model.

\item Recall
\item Design
\end{enumerate}

\chapter{Final Mastery Challenge}
\begin{enumerate}
\item Explain the complete request path from a global client to a service and its data.
\item Predict symptoms for DNS, TCP, TLS, containers, services and databases.
\item Operate a containerized application.
\item Break it with independent faults.
\item Diagnose each fault from evidence.
\item Repair and verify service.
\item Design a multi-region system for millions of users with explicit reliability, security and recovery objectives.
\end{enumerate}

Mastery requires explanation, prediction, operation, controlled failure, diagnosis, repair, recall and transfer.

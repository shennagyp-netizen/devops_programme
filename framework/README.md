# Learning Framework MVP

Standalone, domain-neutral React learning framework.

The framework owns learning semantics, learner state, progression, evidence and assessment semantics, experience intents and controls, provider interfaces, and the React learning experience.

It does not own DevOps curriculum, authentication, PostgreSQL, terminal or SSH implementations, AI vendors, or domain-specific assessment banks.

The neutral demo programme exists only to prove that the framework app runs without a domain programme.

Run: npm install, npm run dev, npm test, npm run typecheck, npm run build.
